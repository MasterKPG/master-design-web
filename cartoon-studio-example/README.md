# Sidekick Pictures: cartoon and comics studio landing page

An example landing page built with the `master-design-web` skill (v3) from this prompt:

> build me a cartoon/comics making studio landing page.

**Fictional demo.** The studio, projects, results and quotes are invented. The client logos are real trademarks (from Simple Icons), used only to show the layout; none of these companies worked with this studio.

The site is a comic page: ink-bordered panels with gutters, caption boxes for labels, speech bubbles for quotes, work shown as comic covers, and an ink-blob mascot in the nav, menu, form, footer and 404 page.

Static site, no build step. Open `index.html`, or serve the folder (`python -m http.server`).

- `index.html`, `styles.css`, `main.js`, `404.html`: the page.
- `assets/video/`: short silent loops and a 30-second reel cut from public-domain cartoons on Wikimedia Commons (Steamboat Willie, Fleischer Superman, Popeye, Betty Boop, Felix the Cat, Bugs Bunny).
- `assets/art/`: public-domain Little Nemo pages.
- `assets/logos/`: client logos. `assets/people/`: portraits for the quotes.

## Placeholders to replace before launch

- Client logos, projects, numbers, quotes and prices.
- The contact form only shows the success message. Wire it to a real inbox or CRM.
