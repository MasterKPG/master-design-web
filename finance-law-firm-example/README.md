# Varick & Thorne: New York finance law firm landing page

An example landing page built with the `master-design-web` skill (v3) from this prompt:

> Build a landing page for a finance law firm in new york.

**Fictional demo.** The firm, partners, deals, figures and quotes are invented. The New York Times clipping is a made-up article set in that paper's style; the paper never published it.

The page is laid out like a financial newspaper: lettered sections (A-F), deals shown as tombstones, job openings as classified ads, and a footer set like the paper's publication box.

Static site, no build step. Open `index.html`, or serve the folder (`python -m http.server`).

- `index.html`, `styles.css`, `main.js`: the page.
- Photos load from Unsplash, so the page needs an internet connection.

## Placeholders to replace before launch

- The firm, partners, deals, numbers, 555 phone numbers, the Pine Street address and the press clipping.
- The consultation form only simulates sending. Wire it to the firm's intake system.
