# Margin: web design agency landing page

An example landing page built with the `master-design-web` skill from the prompt "build me a landing page for a web design agency. use one font only." Open `index.html` in a browser. There's no build step. The font (Geist) loads from Google Fonts and the icons are inline Lucide paths.

Margin, its clients, results, prices, team and quotes are placeholders. The email addresses use the reserved `.example` domain.

## How the skill was applied

- **Identity first.** The world of the site is a designer's desk: wireframe sketches, color swatches, a pinned-up planning wall. The palette came from it: warm paper, near-black ink, one deep blue for actions, and a light "non-photo blue" (the pencil designers mark layouts with) for markup lines. A yellow sticky note is the one accent.
- **One font, as asked.** Geist only, with weight and color doing the hierarchy. Six sizes in total. Large headings tightened to about -3%.
- **Show the product.** For an agency the product is the sites it ships, so the hero shows a client's homepage in a browser frame with the designer's notes on top (spacing redlines, a type label, a comment pin). A switch turns the notes off.
- **Frankenstein wireframe.**
  1. Product-led hero: heading and stats above, the client site below, with real desk photos peeking out behind it.
  2. A rotating ribbon of client logos.
  3. Work as a bento grid, each card with the result after launch. The last card is the open spots.
  4. Process as a clickable multi-section on a timer: workshop, design, build, launch. Each tab has its own visual.
  5. Testimonials without boxes: one big quote, two small ones.
  6. Studio: team photo, faces with name tags on hover.
  7. Two pricing cards with the button under the price, check marks and one item not included.
  8. CTA: heavy tight type over a photo, left-aligned. A small centered footer.
- **Straight-line grid.** Frame lines run the length of the page with crop marks where they meet the section rules.
- **Motion themes, repeated.** Content rises in with a blur, markup lines draw in (hero redline, launch chart, CTA underline), and the hero copy blurs back as you scroll. Everything falls back to static under `prefers-reduced-motion`. The logo ribbon and the tab timer both have pause buttons.
