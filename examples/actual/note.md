# Actual (actual.inc)

- **Source:** screenshots of actual.inc (`actual-hero.png`, `actual-section-1.png`, `actual-section-2.png`, `actual-Actual-section.png`, `actual-CTA.png`)
- **Type:** landing page
- **Take from it:**
  - A hero built on one strong, moody real-world image (hands holding a blue liquid form), not a stock UI shot.
  - A playful, non-standard nav: italic links floating on thin orbital ellipses.
  - The install command in a full-width monospace bar: the product's real action, right under the hero.
  - Line-art illustrations on grey squares, skewed into perspective, as feature visuals.
  - A 3-step "how it works" flow drawn as one continuous line diagram, each step with its own color (blue → red → green) carried into its caption.
  - Light, thin display type with generous space.
- **Related guidelines:** `guidelines/identity-and-site-building.md`, `guidelines/landing-pages.md`
- **Don't take:**
  - The low-contrast grey/teal text on black (e.g. the CTA paragraph). It likely fails contrast; see `guidelines/accessibility.md`.
  - Body paragraphs set in thin weights at small sizes.

**Note:** the reference video describes an "Actual" site that relates to freelancers and agencies with laptops, keyboards and paperclips. These screenshots show actual.inc (an AI computing product), which may be a different site or a redesign. Confirm which one the hero example in `identity-and-site-building.md` refers to.
